# HTTP 5xx 오류율 급증

## 신호 확인

Pod UID별 5xx 누적 카운터의 증가량과 관측 구간을 확인한다. Atienel 로컬 기준은 30초 이내 10건이다. 카운터 리셋과 Pod 교체를 구분하고 관측이 끊긴 구간은 별도로 기록한다. 요청량을 확인할 수 있다면 전체 요청 대비 오류율도 계산한다.

## 원인 구분과 대응

같은 구간의 앱 로그, 요청 지연, 타임아웃, 연결 풀 포화와 최근 배포를 대조한다. 특정 Pod에 집중되는 실패와 모든 복제본에 걸친 공통 의존성 장애를 구분한다. 500의 예외, 502의 연결 실패, 503의 준비 상태나 과부하처럼 확인 가능한 단서를 사용한다.

직전 정상 배포로 롤백하거나 의존성을 복구하는 조치를 증거와 함께 제안한다. 담당자 승인 후 5xx 증가량과 지연이 정상 범위로 돌아오는지 확인한다.
